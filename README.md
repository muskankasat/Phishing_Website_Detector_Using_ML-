# Explainable Phishing Website Risk Detector

An academic ML project that compares **8 classifiers** (classic baselines plus XGBoost, LightGBM, CatBoost and an MLP) on the public UCI Phishing Websites dataset, with cross-validation, a literature comparison and an interactive Streamlit app.

## What this project demonstrates
- Real-world problem: **cybersecurity** (phishing website detection)
- Dataset collection, cleaning (duplicate removal) and stratified 80:20 split
- 8 models, hold-out metrics + 5-fold cross-validation + ROC-AUC + confusion matrices
- Comparison with published results and an experiment showing why published scores look higher (duplicate leakage)
- Interactive Streamlit UI, tests (pytest), linting (ruff) and GitHub Actions CI

## Important limitation
The UCI dataset contains **pre-extracted and encoded website features**. This app does not inspect arbitrary pasted URLs or perform live website scanning. Do not describe it as a live URL scanner.

## Project layout
```
train.py                 data loading, cleaning, training, evaluation, CV, figures
phishing_models.py       model definitions shared by train.py and app.py
app.py                   Streamlit UI (4 tabs)
experiments/duplicate_effect.py   duplicate-leakage experiment
tests/test_pipeline.py   pytest smoke tests
data/raw/                offline copy of the dataset (committed)
results/                 metrics, CV results, literature table, figures
REPORT.md, VIVA_QUESTIONS.md
```

## Setup (Windows PowerShell)
```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
python train.py
python -m experiments.duplicate_effect
streamlit run app.py
```

If PowerShell blocks activation, run the commands in Command Prompt or use:
```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe train.py
.\.venv\Scripts\python.exe -m streamlit run app.py
```

## Quality checks
```
pip install ruff pytest
ruff check .
pytest -q        # run python train.py first
```
GitHub Actions (`.github/workflows/ci.yml`) runs lint, training and tests on every push.

## Offline fallback
`train.py` downloads from UCI via `ucimlrepo`. If that fails, it uses `data/raw/phishing_websites_raw.csv`
(included, 11,055 rows). `results/cleaning_summary.json` records which source was used.

## Generated files
- `data/phishing_websites_cleaned.csv`, `data/test_samples.csv`
- `results/metrics.csv`, `results/cv_results.csv`, `results/duplicate_effect.csv`
- `results/cleaning_summary.json`, `results/feature_importance.csv`
- `results/figures/`: model comparison, CV chart, confusion matrices, feature importance
- `models/model_bundle.joblib`: trained models and feature order

`results/literature_comparison.csv` is hand-curated from cited papers. Everything else is generated by the scripts; do not edit metrics manually.

## Reproducibility
`random_state=42`, stratified 80:20 split, all models evaluated on the same held-out test set. CV uses the training split only. Small numeric differences are possible across package versions.
