# Results

`python train.py` generates `metrics.csv`, `cv_results.csv`, `cleaning_summary.json`, `feature_importance.csv`
and the figures in `figures/`. `python -m experiments.duplicate_effect` generates `duplicate_effect.csv`.

`literature_comparison.csv` is hand-curated from the cited papers (each row has a URL). Use your own generated
outputs in the report; do not copy unverified metrics.
